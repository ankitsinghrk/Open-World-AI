# Research Documentation

Technical documentation for **Open-World AI: Resource-Bounded Open-World Continual Learning**.

## Available Documentation

1. **[Problem Formulation](formulation/README.md)** — Research problem, assumptions, state, actions, constraints, and objectives.
2. **[Chapter 11 – Mathematical Specification (PDF)](formulation/Open_World_AI_Chapter_11_Mathematical_Specification_Updated.pdf)** — V1.0 formal specification of the state representation, joint action space, transition dynamics, reward and objective, resource constraints, feasibility-masked DQN formulation, optimization procedure, and evaluation criteria.
3. **[Reproducibility Guide](REPRODUCIBILITY.md)** — Dataset placement, environment setup, experiment order and commands, checkpoint prerequisites, test status, and generated-output handling.

The mathematical specification documents the current formal design. It does not, by itself, establish that the adaptive policy is effective. The reproducibility guide describes the current scripts and prerequisites; it does not claim that every experiment can be reproduced without obtaining the external dataset and generating prerequisite outputs.

## Documentation Status

The problem formulation, mathematical specification, and reproducibility guide are published. Further implementation notes and expanded experimental protocols may be added after review and verification.

For the current project overview and verified progress, see the [main README](../README.md).
