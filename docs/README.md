# Research Documentation

Technical documentation for **Open-World AI: Resource-Bounded Open-World Continual Learning**.

## Available Documentation

1. **[Problem Formulation](formulation/README.md)** — Research problem, assumptions, state, actions, constraints, and objectives.
2. **[Chapter 11 – Mathematical Specification (PDF)](formulation/Open_World_AI_Chapter_11_Mathematical_Specification_Updated.pdf)** — V1.0 formal specification of the state representation, joint action space, transition dynamics, reward and objective, resource constraints, feasibility-masked DQN formulation, optimization procedure, and evaluation criteria.

The mathematical specification documents the current formal design. It does not, by itself, establish that the adaptive policy is effective.
